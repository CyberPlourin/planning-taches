# Planning des tâches

Une grille de tâches à cocher, utilisable sur téléphone Android (ou tout navigateur).

**Ouvrir l'appli :** https://cyberplourin.github.io/planning-taches/

Sur Android : ouvrir le lien dans Chrome, puis menu ⋮ → « Ajouter à l'écran d'accueil ».

- Mode **Cocher** : toucher une tâche pour la marquer comme faite (ou l'annuler).
- Mode **Modifier** : écrire les tâches, renommer ou ajouter des lignes et colonnes.
- **Tout décocher** pour recommencer (nouvelle semaine), **Sauvegarder / Restaurer** pour garder une copie.

Les données restent sur l'appareil (stockage du navigateur) : rien n'est envoyé sur Internet.
