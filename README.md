# Planning des tâches

Une grille de tâches à cocher, utilisable sur téléphone Android (ou dans n'importe quel navigateur).

👉 **Ouvrir l'appli : https://cyberplourin.github.io/planning-taches/**

---

## Tuto

### 1. Installer l'appli sur un téléphone Android

1. Ouvrez le lien ci-dessus dans **Chrome**.
2. Touchez le menu **⋮** (en haut à droite).
3. Choisissez **« Ajouter à l'écran d'accueil »** (ou **« Installer l'application »**).
4. Une icône apparaît sur l'écran d'accueil : elle ouvre le planning comme une appli.

> Pas besoin de compte ni du Play Store. Une connexion Internet est utile à la première ouverture.

### 2. Les deux modes

En haut de l'écran, deux boutons permettent de passer d'un mode à l'autre :

| Mode | À quoi il sert |
|---|---|
| **Cocher** | Utilisation au quotidien : marquer les tâches comme faites. |
| **Modifier** | Préparer le planning : écrire les tâches, gérer les lignes et les colonnes. |

### 3. Cocher une tâche (mode Cocher)

- **Touchez une tâche** : elle devient verte, barrée, avec un ✓ et la date et l'heure.
- **Touchez-la à nouveau** pour la décocher (en cas d'erreur).
- La **barre en haut** indique l'avancement (par exemple *5/12*).

### 4. Préparer le planning (mode Modifier)

Touchez **Modifier** en haut, puis :

- **Écrire une tâche** : touchez une case (vide ou non), écrivez, puis **OK**.
- **Effacer une tâche** : touchez la case, puis **Supprimer**.
- **Renommer une colonne ou une ligne** : touchez son en-tête (par exemple « Lun » ou « Matin »), changez le texte, puis **OK**.
- **Supprimer une colonne ou une ligne** : touchez son en-tête, puis **Supprimer** et confirmez. ⚠️ Les tâches qu'elle contient sont supprimées aussi.
- **Ajouter une ligne ou une colonne** : boutons **+ Ligne** et **+ Colonne**.
- **Changer le titre** : bouton **Renommer le planning**.

Quand c'est prêt, revenez en mode **Cocher**.

### 5. Recommencer une nouvelle semaine

Le bouton **Tout décocher** (en bas) remet toutes les tâches à « non faite ». Les tâches restent en place : seules les coches sont effacées.

### 6. Sauvegarder et restaurer

- **Sauvegarder (fichier)** : télécharge une copie du planning (fichier `planning-AAAA-MM-JJ.json`, dans le dossier *Téléchargements* du téléphone).
- **Restaurer** : choisissez un fichier de sauvegarde pour remettre ce planning. ⚠️ Le planning actuel est remplacé.

C'est aussi la façon de **passer le planning sur un autre téléphone** : *Sauvegarder* sur l'ancien, envoyer le fichier, puis *Restaurer* sur le nouveau.

## Questions fréquentes

**Où sont enregistrées mes tâches ?**
Uniquement sur le téléphone, dans Chrome. Rien n'est envoyé sur Internet. Chaque téléphone a donc son propre planning.

**Mes tâches peuvent-elles disparaître ?**
Oui, si on efface les données de Chrome ou si on change de téléphone. Pensez à faire **Sauvegarder (fichier)** de temps en temps.

**L'appli a été mise à jour mais je vois toujours l'ancien planning, pourquoi ?**
C'est voulu : une mise à jour ne remplace jamais un planning déjà enregistré, pour ne pas effacer vos tâches. Le planning de départ ne concerne que la toute première ouverture. Pour changer vos colonnes ou lignes, passez en mode **Modifier** (voir le point 4).

**Je ne peux pas supprimer une colonne ou une ligne.**
La dernière colonne et la dernière ligne ne peuvent pas être supprimées : il en faut au moins une de chaque.
